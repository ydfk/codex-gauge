# Design

Codex Gauge 的界面目标是低干扰、高信息密度，并在浅色与深色桌面背景上保持稳定可读。

## Windows

- 顶部状态条只展示 Logo 和选定的剩余额度
- 单击打开固定吸附的统一详情/设置面板
- 详情纵向展示 5 小时与 7 天额度、重置券和数据来源
- 托盘提供显示、刷新、置顶、锁定、设置和退出入口
- 界面由 Slint 绘制，窗口行为由 windows-rs 管理

## macOS

- 只常驻菜单栏，不显示 Dock 图标或桌面浮窗
- 单击展开详情面板，详情与设置在同一面板切换
- macOS 26 使用 Liquid Glass，macOS 15 至 25 使用系统 Material 降级
- 不提供位置、置顶、透明度、锁定或 OLED 位移设置

## 视觉规则

- 紧凑的半透明深色面板与细边框
- 用量条是主要信息表达，状态色保持克制
- 使用平台系统字体，不使用复杂动画或图表库
- 未登录、接口异常和未知值使用中性灰，不伪造为 0

剩余额度颜色阈值：大于 15% 为正常，6% 至 15% 为警告，0% 至 5% 为危险；无限窗口使用薄荷色并明确标记“无限”。
